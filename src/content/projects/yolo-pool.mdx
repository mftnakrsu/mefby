## Overview

A real-time safety system for swimming pools. A custom-trained YOLOv8m model detects the people around a pool and labels each one as an adult or a child, and ByteTrack keeps a persistent ID on every person from frame to frame. A dedicated tool raises a warning when a child is near the pool without an adult.

## Training

The model learned from more than 14,000 labeled people, about half of them adults and half children, in pool scenes labeled with CVAT and Roboflow and combined with a public child-versus-adult dataset. It trained on an A100 in Google Colab with augmentation and early stopping, which ended the run at epoch 78. On validation it reaches a mAP50 of 0.86 and a mAP50-95 of 0.552, and inference takes about 2 ms per image on the A100.

## Running it

A command-line tool processes video files, images, webcams and RTSP streams, and a real-time mode shows the frame rate and lets you change the confidence threshold while it runs. For the edge, scripts set everything up on an NVIDIA Jetson Nano and export the model to TensorRT in FP16, which the project measures at three to five times the speed of PyTorch on the device.
