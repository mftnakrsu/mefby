## Overview

An offline-first analytics workbench for data preparation, visual exploration and statistics, with an extension for guided root-cause analysis. It is built to run on an air-gapped Windows PC, installed from a single bundle, and it makes no outside requests at all. The aim is one tool that does what BI tools, visual analytics tools and statistics packages each do on their own.

## How it works

Data lands in DuckDB through a loader designed for 100 GB in bounded memory: it splits tables into parts, can stop and pick up again after an interruption, checks the free disk space and respects a memory budget. On top sit a visual explorer, whose query descriptions a WebAssembly binary translates into DuckDB SQL inside a sandbox with no file or network access; pivot tables and a worksheet on Perspective; formulas compiled to SQL; and charts. An extension API with its own test kit lets the root-cause analysis add its pages without any browser code.

## Quality

Every milestone ends with a visual QA loop: screenshots of every screen in Chromium and WebKit at three resolutions, click-through tests of the main flows, automatic checks for console errors, outside requests and accessibility rules, and visual regression baselines for the screens that have been approved.
