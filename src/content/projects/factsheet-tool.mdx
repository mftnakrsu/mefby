## Overview

An editorial workspace on Microsoft Dataverse that I built at RADIAITE for the same international accessibility organization. Its editors use it to take factsheets, short structured write-ups, from the first draft to publication, in one place instead of a chain of documents and emails.

## What it does

Each factsheet moves through a multi-step status workflow, and only the allowed transitions between steps are possible. AI helps with drafting and with checking a draft. An external review page on Power Pages lets the people a factsheet describes read their draft and comment on it before it goes out.

## How it is built

The whole application is built from code rather than by clicking through the designer: Python scripts that set it up through the Dataverse Web API, a C# plug-in that enforces the status transitions, and the web resources that run in the browser. Offline checks run without any connection, and end-to-end proofs run against a development environment before each release, so a change can be reviewed and repeated like any other code.
